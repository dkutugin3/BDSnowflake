# Отчет по лабораторной работе

Лабораторная работа N1 по дисциплине "Анализ больших данных".

Цель работы: загрузить исходные CSV-данные в PostgreSQL и преобразовать их в аналитическую модель данных типа "звезда" с таблицей фактов и таблицами измерений.

## Что реализовано

1. Поднимается контейнер PostgreSQL.
2. Создается таблица `mock_data` для исходных CSV данных.
3. Загружаются 10 CSV файлов из папки `исходные данные`.
4. Создаются таблицы аналитической модели.
5. Данные из `mock_data` раскладываются по таблицам фактов и измерений.
6. Выполняется проверка, что количество строк в `fact_sales` совпадает с количеством строк в `mock_data`.

В результате в базе получается:

- `mock_data` - 10000 строк исходных данных;
- `fact_sales` - 10000 строк фактов продаж;
- набор таблиц `dim_*` для анализа продаж по датам, покупателям, продавцам, товарам, магазинам и поставщикам.

## Запуск

Для запуска PostgreSQL:

```bash
docker compose up -d
```

Для остановки:

```bash
docker compose down
```

## Модель данных

Используется упрощенная аналитическая модель "звезда".

В центре находится таблица фактов:

- `fact_sales`

Вокруг нее находятся таблицы измерений:

- `dim_date`
- `dim_customer`
- `dim_seller`
- `dim_product`
- `dim_store`
- `dim_supplier`

Таблица `mock_data` используется как staging-слой. В нее сначала загружаются сырые данные из CSV, а затем из нее заполняется аналитическая модель.

## SQL-скрипты

`sql/init/01_create_staging.sql`

Создает таблицу `mock_data`, структура которой соответствует CSV-файлам. Дополнительно добавлены поля:

- `source_row_id` - уникальный идентификатор строки;
- `source_file` - имя CSV-файла, из которого пришла строка.

`sql/init/02_load_mock_data.sql`

Загружает 10 CSV-файлов в `mock_data`.

`sql/init/03_create_star_schema.sql`

Создает таблицы аналитической модели:

- `fact_sales`;
- `dim_date`;
- `dim_customer`;
- `dim_seller`;
- `dim_product`;
- `dim_store`;
- `dim_supplier`.

`sql/init/04_populate_star_schema.sql`

Заполняет таблицы аналитической модели из `mock_data`.

Перед загрузкой выполняется очистка аналитических таблиц:

```sql
TRUNCATE TABLE ... RESTART IDENTITY CASCADE;
```

`sql/manual/analysis_queries.sql`

Содержит проверочные и аналитические запросы:

- подсчет строк в `mock_data`;
- подсчет строк по каждому CSV-файлу;
- подсчет строк в таблицах фактов и измерений;
- продажи по месяцам и категориям товаров;
- топ стран магазинов по сумме продаж.
